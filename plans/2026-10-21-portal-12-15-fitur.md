# Plan 12–15 — Portal: fitur dashboard, indikator, atlas, gmti/spasial/hotel

Empat plan dengan pola yang sama persis dengan plan 11 (`docs/pola-fitur.md` di repo portal).
Setiap plan adalah satu PR. Keempatnya boleh dikerjakan paralel setelah 11 selesai.

## Bagian bersama untuk keempat plan

Isi setiap PR:

1. **Backend `Features/<Fitur>`.**
   - Rute Laravel untuk endpoint KONTRAK yang bersangkutan.
   - Contract → Source → Service → Resource.
   - Kelas cache/snapshot sesuai kolom "Kelas".
2. **Frontend layer `<fitur>`.**
   - Halaman di KONTRAK §1 yang dimiliki fitur ini.
   - Composable `use<Fitur>()` berisi satu fungsi per endpoint.
   - Komponen khusus fitur, diambil dari komponen React di inventaris dan disalin kelas per
     kelas.
3. **`docs/skenario/<fitur>.md`.** Daftar skenario ber-ID, lalu satu tes per ID (Pest Feature,
   Pest Unit, Vitest, Playwright e2e).
4. **`tests/parity/<fitur>.spec.ts`** untuk semua rute fitur.

Aturan:

- Komponen dipindah ke `shared` hanya bila dipakai dua fitur. Pemindahan dilakukan sebagai
  commit pertama PR.
- **Konstanta tampilan** (teks hero, MomNote, label tanggal yang ditulis tangan, C §4.4) ada di
  `layers/<fitur>/constants.ts` dengan komentar sumber `platform-v2/<file>:<baris>`.
- Paritas: visual ≤ 2%, himpunan angka identik, interaksi sama (SPEC §7). Perbedaan yang
  diizinkan hanya P1–P5 dan Nav "AI". P6 ditiru.
- Sources kelas T memakai `Shared/Tetap/BacaTetap` (plan 10). Rute didaftarkan lewat
  `Route::apiGet` dengan `kelas` dan, bila ada, `varian`.
- Redirect lama **sudah** dibuat plan 10. Plan fitur hanya menambah tes e2e redirect yang
  menyangkut rutenya.

Gate lokal: sama dengan plan 11, dengan nama berkas tes fitur.

- **Inventaris:** D §2.1, §2.2, §2.9; A §5.4 (`GmtiMapView`).
  - `/gmti` daftar tempat berhalaman server (200).
  - `/spatial`:

    - strip filter `<details class="frosted">`, chip gabungan "Hotel" dan "Ramah Muslim";
    - pencarian debounce 180 ms, dropdown wilayah (30 nilai, ditiru);
    - legenda;
    - tinggi `calc(100dvh - 78px)` + ResizeObserver.

    ini **akan berisi**, sementara produksi kosong. Paritas visual untuk halaman ini dinilai

    pemilik. Catat di PR.
- **Interaksi wajib e2e:**
  - gmti: filter pilar, kota, cari + paging;
  - spatial: toggle choropleth, chip kategori, cari, filter wilayah, reset, popup, "Coba lagi"
    saat API gagal;

- Paritas `/spatial` hanya untuk panel UI. Tile peta di-mask.
